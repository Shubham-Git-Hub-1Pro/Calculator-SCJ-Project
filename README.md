# 🧮 Calculator SCJ Project

A modern, clean, and responsive calculator built using **HTML, CSS, and JavaScript**.  
This project performs basic arithmetic operations and supports both **mouse input** and **keyboard input**, providing a smooth and intuitive user experience.

---

## 🚀 Live Demo

👉 Deployed on **Vercel**  
🔗 https://calculator-scj-project.vercel.app

---

## ✨ Features

- ➕ Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- ⌨️ Full **keyboard support**
  - Numbers (0–9)
  - Operators (+ − × ÷)
  - Enter (=)
  - Backspace (delete)
  - Escape (clear)
- 🧠 Smart calculator behavior  
  - Shows calculation and result separately
- 🎨 Modern & premium UI design
- 📱 Responsive (works on desktop & mobile)
- 🌐 Custom favicon and browser tab title

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & UI  
- **JavaScript (Vanilla JS)** – Logic & interactivity  

No frameworks. No libraries. Pure frontend.
